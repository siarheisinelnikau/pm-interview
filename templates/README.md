# Working templates

[Back to questions](../README.md)

Use these short templates for case practice or adapt them to the project's decision authority and risk. Example entries are illustrative.

| Template | Purpose |
| --- | --- |
| [Project brief](project-brief.md) | Align objective, boundaries, ownership, and success |
| [Status report](status-report.md) | Communicate forecast and decisions needed |
| [RAID log](raid-log.md) | Track uncertainty, problems, and external needs |
| [Change request](change-request.md) | Make scope trade-offs and approval visible |
| [Release readiness](release-readiness.md) | Organize go/no-go evidence and exceptions |
| [Presales handover](presales-handover.md) | Transfer commitments, assumptions, and unresolved questions |

For interview use, explain why each field matters and remove fields that do not support a decision.
