# RAID log

[All templates](README.md)

This template uses **Risks, Assumptions, Issues, Dependencies**.

| ID / type | Description and objective affected | Owner | Evidence / likelihood / impact | Response or next action | Trigger / due date | Status / decision |
| --- | --- | --- | --- | --- | --- | --- |
| R-01 / Risk | Provider certification may delay launch | PM | Slot not yet confirmed; assess impact | Reserve slot and check entry conditions | Before integration completion | Open |
| A-01 / Assumption | Client sandbox supports required roles | Technical owner | Unverified | Validate with a representative access test | Before estimate is committed | Open |
| I-01 / Issue | Required credentials are unavailable | Client owner | Access test failed | Restore access or agree alternative | Current blocker | Escalation time agreed |
| D-01 / Dependency | Client supplies approved test data | Client owner | Acceptance conditions agreed | Deliver and verify dataset | Before integration test | Planned |

For risks, record the cause, uncertain event, consequence, residual exposure, and acceptance authority where needed. For dependencies, define what counts as ready. Preserve links when a risk becomes an issue.
