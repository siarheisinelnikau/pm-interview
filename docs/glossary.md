# PM interview glossary

[Back to questions](../README.md)

| Term | Meaning in this guide |
| --- | --- |
| Acceptance criteria | Observable conditions for a specific item or deliverable |
| Baseline | An approved reference used to assess variance |
| Benefit | A valuable result of the change, often realized after delivery |
| Business case | Rationale for investment, including options, costs, benefits, and uncertainty |
| Critical path | Longest-duration dependency path in the current schedule model |
| RAID | Risks, Assumptions, Issues, Dependencies; state the convention because usage varies |
| RACI | Responsible, Accountable, Consulted, Informed |
| RAG | Red/Amber/Green status using agreed thresholds |
| WBS | Work Breakdown Structure: decomposition of project scope |
| WIP | Work in progress: started but unfinished items |
| Cycle time | Elapsed time between the workflow's defined start and finish |
| Lead time | Elapsed time across stated request/change-to-delivery boundaries |
| Throughput | Count of items completed per unit of time |
| Work item age | Elapsed time since an unfinished item started |
| Forecast | Evidence-based prediction under stated assumptions |
| Target | Desired result or date |
| Commitment | Promise made with the relevant authority |
| DoD | Definition of Done: required quality state for an Increment in Scrum |
| MVP | Minimum Viable Product: a bounded solution that delivers value or learning |
| UAT | User Acceptance Testing with representative business users |
| PV / EV / AC | Planned Value / Earned Value / Actual Cost |
| CPI / SPI | EV divided by AC / EV divided by PV |
| ETC / EAC | Estimate to complete / estimate at completion |
| RFI / RFP | Request for Information / Request for Proposal |
| SOW | Statement of Work; interpret it within the actual contract |
| T&M | Time and materials commercial arrangement |
| POC | Proof of concept testing a defined uncertainty |
| SLI / SLO / SLA | Service Level Indicator / Objective / Agreement |
| RTO / RPO | Recovery Time Objective / Recovery Point Objective; time-to-restore target / acceptable data-loss window |
| BIA | Business Impact Analysis: identifies consequences, dependencies, and recovery priorities for disruption |
| Business continuity / DR | Sustaining important business activities / restoring affected technology and data |
| Hypercare | Time-bounded additional support after launch with exit criteria |
| PHI / ePHI | Protected Health Information / electronic PHI in the HIPAA context |
| EHR / EMR | Electronic Health Record / Electronic Medical Record; usage varies by setting |
| FHIR | Fast Healthcare Interoperability Resources, published by HL7 |
| SaMD | Software as a Medical Device; classification depends on the applicable framework |
| KYC / AML | Know Your Customer / Anti-Money Laundering |
| Origination / servicing | Establishing and funding a loan / managing the ongoing account and borrower relationship |
| Claims adjudication | Payer assessment of a claim under the relevant coverage and payment rules |
| SCA | Strong Customer Authentication in the applicable payment-services context |
| PCI DSS | Payment Card Industry Data Security Standard |
| Reconciliation | Comparing authoritative records and resolving discrepancies |
| Idempotency | Repeating an operation under its defined contract without duplicating its effect |
| IAM / MFA | Identity and Access Management / Multi-Factor Authentication |
| SIEM / SOC | Security Information and Event Management / Security Operations Center |
| SOC assurance report | System and Organization Controls reporting; a different use of SOC from Security Operations Center |
| ISMS | Information Security Management System; ISO/IEC 27001 addresses its requirements |
| Shared responsibility | Allocation of provider and customer duties for the actual service and operating arrangement |
| CVE / CVSS / KEV | Vulnerability identifier scheme / severity scoring system / CISA's known-exploitation catalog |
| DORA research | Software delivery performance research and metrics |
| EU DORA | Digital Operational Resilience Act; a different use of the same acronym |
| STAR | Situation, Task, Action, Result for a behavioral answer |

Definitions are short navigation aids. Open the relevant question for boundaries, examples, and references.
